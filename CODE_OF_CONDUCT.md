# Code of Conduct

This policy applies to repository issues, pull requests, reviews, discussions,
and other project spaces. / 本准则适用于仓库 Issue、PR、代码审查及其他项目交流空间。/ 本規範はIssue、PR、レビューなど本プロジェクトの交流場所に適用されます。

## Expected behavior / 期望行为 / 期待される行動

- Be respectful, specific, and constructive.
- Discuss code and behavior without attacking the person who wrote or reported it.
- Respect different experience levels, languages, identities, and accessibility needs.
- Protect private information. Redact personal paths, account data, credentials, saves, and logs before sharing them.
- Respect copyright and asset provenance. Do not pressure contributors to upload material they cannot legally redistribute.

请保持尊重、具体和建设性的交流；讨论代码与行为，不攻击作者或反馈者；尊重不同经验、语言、身份与无障碍需求；公开信息前先清除个人路径、账号、凭据、存档和日志中的隐私内容；尊重版权与素材来源。

敬意を持って具体的かつ建設的に交流し、個人ではなくコードと挙動を議論してください。経験、言語、属性、アクセシビリティの違いを尊重し、個人情報や認証情報を公開せず、著作権と素材の出典を守ってください。

## Unacceptable behavior / 不可接受行为 / 禁止される行為

- Harassment, threats, discrimination, sexualized content, or deliberate intimidation.
- Personal attacks, repeated disruption, spam, or knowingly misleading reports.
- Publishing another person's private information without explicit permission.
- Submitting malware, stolen credentials, or material known to lack redistribution rights.
- Retaliation against someone who raises a good-faith concern.

## Enforcement and reporting / 执行与报告 / 対応と報告

Maintainers may edit or remove content, close or lock threads, reject contributions,
or temporarily or permanently restrict participation when behavior violates this
policy. Enforcement should be proportional, documented when practical, and
focused on protecting the community.

For ordinary moderation concerns, contact the maintainer through the public
contact options on [AiurArtanis's GitHub profile](https://github.com/AiurArtanis).
If confidentiality is required and no private contact option is available, open
a minimal issue asking for private contact without including sensitive details.
Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md).

维护者可删除不当内容、关闭或锁定讨论、拒绝贡献，或限制参与。普通管理问题可通过维护者 GitHub 主页提供的联系方式反馈；如需保密但没有可用私密渠道，请只创建一条不含敏感细节的 Issue 请求私下联系。安全漏洞必须按 [SECURITY.md](SECURITY.md) 私密报告。

メンテナーは違反内容の削除、スレッドの閉鎖、貢献の拒否、参加制限を行う場合があります。通常の運営上の問題はメンテナーのGitHubプロフィールにある連絡手段を利用し、機密性が必要な場合は詳細を書かずに非公開連絡を依頼してください。脆弱性は [SECURITY.md](SECURITY.md) の非公開手順で報告してください。
